# Shared style notes

All templates use the same shell:

- 600px max-width content card centered on a paper background (#FAF7F2)
- Bite Book logo (white-on-black) in a black 96px square at top
- Display headline in Barlow Condensed (with system fallback for email clients)
- Body in system sans-serif (no web font — email clients hate them)
- Accent button: solid #B45309 with #FAF7F2 text
- Footer: small ink-color text with support email link
