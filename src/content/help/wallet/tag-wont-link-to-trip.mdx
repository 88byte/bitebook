You’re on a trip page, you tap the tag picker on the **Action needed** card, and your tag isn’t in the list. The dropdown reads **— No matching items in your wallet —**. Here’s why that happens.

## The four causes

The picker only shows wallet items that meet all of these:

1. The item type is **Tag** (the action row is asking for a tag specifically — your licenses won’t show up here).
2. The item is **not archived**.
3. The item is **not already tagged out**.
4. The item’s **Valid to** date is in the future (not expired).

If any one of those fails, the tag drops out of the dropdown.

## Other things that might be happening

- **The trip has no species set.** The tag row only appears when the trip has a species targeted. If your guide created the trip without a species, you won’t see a tag row at all — only a license row.
- **You don’t have any tags in your wallet yet.** Tap **Add new** on the action row to create one.
- **The state is different.** This is NOT a hard filter. Tags from other states still show in the dropdown — items matching the trip’s state float to the top, but everything else is still picked from. So if you only see one option but it’s from the wrong state, that’s on you to fix; the picker won’t hide it.

## Fix it

Go to **Wallet**, find the tag, and check what bucket it’s in:

- **Done** (tagged out) — open it and tap **Mark as active** to bring it back into rotation.
- **Expired** — the dates are past. Add a new tag with current dates. (See: [What 'expired' means](/app/h/support/handle-expired-wallet-items).)
- **Archived** — open the archived deck (toggle into the archived view), open the tag, tap **Restore**.
- **Not there at all** — tap **Add new card** to create the tag, fill in the species and number, save.

Once the tag is back to Active, return to the trip page and pick it from the dropdown.
