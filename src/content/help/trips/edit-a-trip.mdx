Trips aren’t set in stone. Dates shift, parties change, the gate code gets updated. Editing is one tap from the trip detail page.

## Edit the basics

1. From the dashboard, tap the trip.
2. Tap **Edit** at the top right.
3. Update any field — name, dates, location, activity, species, method, notes.
4. Tap **Save**.

The trip card updates immediately. If a hunter was already invited, they see the new dates the next time they open Bite Book.

## What you can’t change

A few things are locked once a trip exists:

- **State.** Picking a different state mid-trip would invalidate the harvest report template. If you put the wrong state on a trip, delete the trip and create a new one. (See: [How to cancel or delete a trip](/app/support/cancel-or-delete-a-trip).)
- **Hunters who have already signed waivers.** You can remove them from the trip but the signed waivers stay attached to the trip’s history.

## Edit hunters

Hunters get their own section. Tap **Manage hunters** on the trip detail page to add or remove people. Full details: [How to add or remove hunters mid-trip](/app/support/add-remove-hunters-mid-trip).

## Edit harvests

Harvests are logged separately from the trip itself. From the trip detail page, scroll to the **Harvests** section and tap any entry to edit. You can edit harvests until the trip is wrapped up.
