Trips aren’t set in stone. Dates shift, parties change, the gate code gets updated. Editing is one tap from the trip detail page.

## Edit the basics

1. From the dashboard or trips list, tap the trip.
2. The trip detail page IS the editor — there’s no separate Edit screen. Update any field directly: name, dates, location, activity, species, method, notes.
3. Changes save as you type. You’ll see a small saving indicator while a write is in flight.

## State is editable

Even after a trip is created, you can change the state on the trip detail page. If you put the wrong state on a trip and have already mapped a state log doc, you may need to re-pick a different log template before generating the next PDF.

## Edit hunters

Hunters get their own section. Tap **Manage hunters** on the trip detail page to add or remove people. Full details: [How to add or remove hunters mid-trip](/app/support/add-remove-hunters-mid-trip).

## Edit harvests

Harvests are logged separately from the trip itself. From the trip detail page, scroll to the **Harvests** section and tap any entry to edit. You can edit harvests until the trip is wrapped up.
