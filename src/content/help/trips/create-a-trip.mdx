A trip in Bite Book is the container for a hunt. It holds the dates, the hunters, the species, the harvests you log, and the state report you generate at the end. Get the fields right when you create it and the rest of the trip is downhill.

## Start

From the dashboard, tap **Add trip**. You land on a form with six sections.

## Trip overview

- **Trip name.** What you’ll search for later. Use the season + the species + the party. “Fall black bear — Johnson party.” Don’t use a date — Bite Book already tracks dates.
- **Start date / End date.** First and last day in the field. Set both to the same day for a single-day hunt.
- **Activity.** Hunting or fishing. Pick one — they’re mutually exclusive.

## Location

- **State** (required). Picks the right harvest log template. If you guide in two states, create one trip per state.
- **City** (optional).
- **Zone or unit** (optional). Some states want this on the report.
- **County** (optional). A few states want this on the report.

## Hunt details

- **Species targeted** (optional). One species per trip.
- **Method** (optional). Rifle, bow, muzzleloader, and so on.

## Notes

Free text. Anything you want to remember — gate codes, who’s bringing what, weather notes from past years. Doesn’t go on any state form.

## Docs

Pre-attach waivers or resources from your library so they’re already on the trip when hunters land on it.

## Hunters

Leave empty if you don’t know who’s coming yet. Otherwise pick existing hunters from your network or invite a new one by email inline. New hunters get an invite as soon as you save.

Tap **Save**. Your trip lands on the dashboard.
