Bite Book ships pre-mapped harvest log templates for several states. If yours isn’t one of them yet, you can upload the official PDF from your state and map it yourself. After that, generation works the same as with any built-in template.

## Spotting the gap

In **onboarding step 3**, the state log dropdown only shows templates for the state you set on your profile. If we don’t have one for your state, the dropdown contains only one option — **I'll upload my own (skip for now)** — plus a help line that reads:

> We don't have a Bite Book template for {state} yet — upload yours from the docs library after you finish setup.

Tap **Skip for now**, finish onboarding, then upload yours.

## Upload the form

1. Get the official PDF from your state agency. Bite Book accepts PDF only, up to 25 MB.
2. Tap **Documents** in the sidebar.
3. Tap **Upload doc**.
4. Pick **Harvest log** as the kind.
5. Set the **Label** (something like "Texas Annual Harvest Report 2026").
6. Set the **State** if it’s state-specific. Leave blank for a federal form or anything generic.
7. Attach the PDF and tap **Save doc**.

## Map the fields

Once the upload lands, you map it.

1. Open the doc you just uploaded.
2. Scroll to **Field mapping**. Tap **Set up mapping**.
3. Tap **Start AI mapping**. AI reads the PDF and pre-fills mapping suggestions in 10–20 seconds.
4. Review every field. The AI is suggesting — you’re approving. Edit anything wrong.
5. Tap **Mapping Complete** at the bottom.

You can re-run the AI any time with **Re-run AI** if the first pass missed something.

## Make it your default (optional)

If this is the form you’ll generate every trip, set it as your default in **Settings** under the Profile tab. Pick the doc from the **Default log doc** dropdown. From then on, **Hunt logs** auto-selects it on every new trip.

## Generate from it

Once mapping is complete, your custom log appears in the dropdown on the trip’s **Hunt logs** page exactly like a Bite Book template would. Tap **Generate Filled Out Log** and it fills in.

If your state ships an updated form for next season, upload the new version as a separate doc and map it again. The old one stays for trips you’ve already generated.
